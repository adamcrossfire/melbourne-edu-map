# 墨尔本教育居住区互动地图

手机适配的互动地图：把墨尔本 23 个教育居住区的排名叠加到 suburb 边界上，并标注私立 / 天主教学校、政府中学与选择性学校。

- 两套评分可切换：**注重公立资源**（政府中学学区 25 + 私校可达性 20）与**注重私立资源**（私校距离 35 + 政府学区 15）
- 点区域：显示相关学校、直线距离、分项评分、House / Townhouse / Unit 价格与适合人群
- 点私校：显示 3 km / 5 km 圈
- 筛选：孩子性别、房型、预算、私校等级

数据日期：2026-09-29。距离为 suburb 代表点到校区的直线距离（OpenStreetMap 坐标），边界来自 ABS Suburbs and Localities 2021，底图 © Esri。

签约前必须使用官方 Find my School 按具体门牌地址和目标 enrolment year 核验。居住在学校附近仅改善通勤与教育生态，不构成录取保证；请按学校官网要求提前登记或申请。
